## Overview

AquaSens is an intelligent agricultural platform that uses machine learning to predict crop irrigation needs based on environmental data. It features interactive dashboards for real-time sensor data visualization and predictive analytics, helping farmers make data-driven irrigation decisions.

## Key Features

- **ML Prediction Engine**: Analyzes soil moisture, temperature, humidity, and historical data to predict when and how much irrigation is needed.
- **Real-Time Dashboards**: Interactive data visualizations built with Chart.js and React, displaying live sensor feeds and predictions.
- **Sensor Data Integration**: Connects to environmental sensors and processes incoming data streams.
- **Predictive Analytics**: Trend forecasting and anomaly detection to alert farmers of unusual conditions.

## Technologies Used

- **Front-End**: React.js (TypeScript), Chart.js, Tailwind CSS
- **Back-End**: Node.js, Express.js, REST APIs
- **Database**: PostgreSQL
- **AI / ML**: Python, Scikit-learn, time-series prediction models
- **Language**: TypeScript

## Challenges and Learnings

Working with time-series sensor data introduced me to the challenges of noisy, irregular data. I implemented preprocessing pipelines to clean and normalize inputs before feeding them to the model, which significantly improved prediction accuracy. TypeScript's strong typing was invaluable for managing complex data structures from multiple sensor sources.
